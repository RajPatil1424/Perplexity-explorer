About Perplexity Explorer

This educational tool loads DistilGPT-2 through Transformers.js, tokenizes text, evaluates token probabilities, and calculates perplexity entirely in your browser.

  • No API key or backend is required.
  • Model files are downloaded from Hugging Face after your first analysis.
  • Perplexity is computed from real model logits using negative log likelihood.
  • Generated text is distinct from the original sentence.
